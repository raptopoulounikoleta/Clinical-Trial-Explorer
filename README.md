# 🧬 Clinical Trial Data Explorer

## Overview
This repository contains a professional web application built with Python and Streamlit, designed to visualize and filter clinical trial patient data. It demonstrates foundational skills in data wrangling, interactive UI development, and data infrastructure—bridging the gap between raw clinical datasets and actionable insights.

## ✨ Key Features
* **Dynamic File Uploader:** Users can drag and drop their own clinical dataset (CSV) directly through the sidebar.
* **Interactive Filtering:** Filter patient cohorts dynamically using multi-select treatment options and age sliders.
* **Real-Time KPIs:** Automatically calculated metrics (Total Patients, Average Age, Treatment Groups) that update instantly based on active filters.
* **Data Visualization:** Clean, responsive bar charts visualizing patient distribution across different treatment groups.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Streamlit, Pandas
* **Concepts:** Data Cleaning, UI/UX for Data Science, Virtual Environments (`venv`)
